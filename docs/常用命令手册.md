# 北华校园助手 · 常用命令手册

> 适用对象：项目开发者/部署者。覆盖两个环境：**本地 Windows 开发** 和 **阿里云 ECS + Docker 运行**。
> 服务器公网地址：`http://<你的公网IP>:8000`（在阿里云控制台实例列表里能看到）
>
> 第一次部署 / 从本地更新到服务器，建议照 [部署到云服务器.md](部署到云服务器.md) 的步骤走，那篇是逐条带解释的完整流程；本篇是日常速查。

## 一、本地 Windows 环境

### 1.1 首次安装依赖（只装一次）

| 命令 | 作用 |
|---|---|
| `python -m venv .venv` | 创建虚拟环境 |
| `.venv\Scripts\python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple` | 用清华镜像装依赖 |
| `.venv\Scripts\python -m playwright install chromium` | 安装浏览器 MCP 用的 Chromium（可选） |
| `scripts\install.bat` | 一键完成上面三步 |

> 注意：Windows 的 `.venv` 结构是 `Scripts\python.exe`，**不能传到 Linux 上用**，Linux 需要 `bin/python`。

### 1.2 启动 / 停止

| 命令 | 作用 |
|---|---|
| `scripts\start.bat` | 一键启动并自动打开浏览器（推荐） |
| `.venv\Scripts\python run.py` | 等价的命令行启动 |
| `.venv\Scripts\python -m uvicorn app.main:app --host 0.0.0.0 --port 8000` | 不带自动开浏览器的启动方式 |
| 关闭黑色控制台窗口 / `Ctrl+C` | 停止服务 |

访问地址：http://127.0.0.1:8000 ，管理后台：http://127.0.0.1:8000/admin

### 1.3 配置（.env）

| 文件 | 作用 |
|---|---|
| `.env` | 程序真正读取的配置：`DEEPSEEK_API_KEY`、`AMAP_API_KEY`、`PORT` 等 |
| `.env.example` | 配置模板，程序不读它，只作示范 |

```ini
DEEPSEEK_API_KEY=sk-你的Key
AMAP_API_KEY=你的高德Web服务Key
PORT=8000
```

> 代码兼容逻辑：会先读项目内 `.env`，再读上级目录 `.env`（本地曾把 DeepSeek Key 放在 `E:\pythonProject1\.env`，所以项目里看不到也正常）。

### 1.4 其他常用

| 命令 | 作用 |
|---|---|
| `scripts\reset_db.bat` | 删除 `data\campus.db`，下次启动自动重建种子数据 |
| `.venv\Scripts\python tests\eval_agent.py` | 知识库检索 + 意图规则评测 |
| `.venv\Scripts\python tests\test_rag_and_notify.py` | **RAG 混合检索 + 主动推送**自检（28 项，用临时库，不动正式数据） |
| `.venv\Scripts\python tests\e2e_http_check.py` | 打真实接口的端到端自检（20 项，需服务已启动） |
| `.venv\Scripts\python scripts\build_kb_files.py` | 重新生成 `seed/kb_files` 里的知识库文件（md/PDF/表格） |
| `.venv\Scripts\python scripts\pack_for_upload.py` | 打包成 `bhu_campus_agent_upload.zip`（自动排除 .venv/data/logs/.env），用于上传到服务器 |
| `Get-NetTCPConnection -LocalPort 8000` | 查看 8000 端口占用 |

停止本地服务的两条命令：

```powershell
# 方式一：找到占用 8000 的进程并结束
(Get-NetTCPConnection -LocalPort 8000 -State Listen).OwningProcess | Sort-Object -Unique | ForEach-Object { Stop-Process -Id $_ -Force }

# 方式二：后台启动（日志落到 logs\ 下，方便排查）
Start-Process -FilePath ".venv\Scripts\python.exe" -ArgumentList "-m uvicorn app.main:app --host 127.0.0.1 --port 8000" -RedirectStandardOutput "logs\dev_out.log" -RedirectStandardError "logs\dev_err.log" -WindowStyle Hidden
```

## 二、阿里云 ECS + Docker 环境

> 服务器结构：`/project`（dockerfile、bhu_campus_agent/）
> 容器名：`campus`，镜像名：`campus-agent`，端口：`8000`。
>
> **更新代码别用 SFTP 拖整个文件夹**：本地 `.venv` 有近万个文件，会卡住。先跑
> `python scripts\pack_for_upload.py`，把生成的 zip 传上去，服务器上
> `python3 -m zipfile -e bhu_campus_agent_upload.zip bhu_campus_agent/` 解压覆盖即可。
>
> **重要**：Dockerfile 从 `bhu_campus_agent/requirements.txt` 读依赖清单（只保留一份，避免两处不同步）。
> 所以 `/project` 下必须同时有 `dockerfile`、`.dockerignore` 和 `bhu_campus_agent/` 三样东西。
> 老的 `/project/requirements.txt` 已经没用了，留着不影响。

### 2.1 构建与运行

| 命令 | 作用 |
|---|---|
| `cd /project` | 进入构建目录（dockerfile 所在位置） |
| `docker build -t campus-agent .` | 按 Dockerfile 制作镜像（改代码/依赖后必须重跑） |
| `docker rm -f campus` | 先删旧容器（改代码后重建必做） |
| `docker run -d --name campus --restart=always -p 8000:8000 -v /project/bhu_campus_agent/data:/app/data -e PYTHONUNBUFFERED=1 -e DEEPSEEK_API_KEY=sk-你的Key -e AMAP_API_KEY=你的高德Key campus-agent` | 后台运行容器，映射端口，注入 Key，挂载数据目录 |
| `docker ps` | 查看运行中的容器 |

完整三连（改完代码后照抄即可）：

```bash
cd /project
docker build -t campus-agent . && docker rm -f campus && \
docker run -d --name campus --restart=always -p 8000:8000 \
  -v /project/bhu_campus_agent/data:/app/data \
  -e PYTHONUNBUFFERED=1 \
  -e DEEPSEEK_API_KEY=sk-你的Key \
  -e AMAP_API_KEY=你的高德Key campus-agent
```

> `-v 宿主机目录:容器目录` 的作用：把数据库和上传的知识文件放到宿主机上。
> 加上它以后，`docker rm -f campus` 重建容器**不会丢审批记录、通知和上传的文档**；
> 不加的话数据库只存在容器里，删容器就没了。
>
> **两个 Key 都要 `-e` 传**：项目的 `.dockerignore` 把 `.env` 排除在镜像外，容器读不到服务器上的 `.env`。
> 少了 `AMAP_API_KEY`，高德 MCP 会 offline，路线/天气就不能用了。

常用参数解释：

| 参数 | 含义 |
|---|---|
| `-d` | 后台运行，不占终端 |
| `--name campus` | 容器起名 campus，方便后续用名字操作 |
| `-p 8000:8000` | 服务器 8000 → 容器 8000，外网访问入口 |
| `-e 名=值` | 注入环境变量。DeepSeek 和高德 **两个 Key 都要传**（容器读不到宿主机 `.env`） |
| `--restart=always` | 容器异常退出/服务器重启时自动拉起（推荐加上） |
| `-v 宿主:容器` | 目录挂载，做数据持久化（见上面说明） |
| `-e PYTHONUNBUFFERED=1` | 让 `print()` 立刻输出，否则 `docker logs` 看不到 `[init]` 那几行 |

### 2.2 日常运维

| 命令 | 作用 |
|---|---|
| `docker logs campus --tail 50` | 看最近 50 行日志 |
| `docker restart campus` | 重启服务 |
| `docker start campus` | 启动已停止的容器 |
| `docker stop campus` | 停止容器 |
| `docker rm -f campus` | 删除容器（**会丢容器内数据**，重建前先确认） |
| `docker exec -it campus bash` | 进入容器内部 |
| `docker inspect -f '{{.HostConfig.RestartPolicy.Name}}' campus` | 确认是否开机自启（应输出 always） |
| `systemctl is-enabled docker` | 确认 Docker 开机自启（应输出 enabled） |
| `systemctl enable docker` | 设置 Docker 开机自启 |

### 2.3 重启电脑/服务器后的检查顺序

```bash
docker ps                # 1. campus 是否 Up
docker logs campus --tail 30   # 2. 是否 Application startup complete
curl -s http://127.0.0.1:8000 | head -5   # 3. 本机能否返回 HTML
curl -4 ifconfig.me      # 4. 当前公网 IP
```

手机流量访问 `http://公网IP:8000` 验证外网。

### 2.4 防火墙 / 网络排查

```bash
ss -tlnp | grep 8000     # 服务是否监听 0.0.0.0:8000
systemctl status firewalld --no-pager | head -3   # 服务器防火墙状态（inactive=不拦截）
sudo firewall-cmd --permanent --add-port=8000/tcp && sudo firewall-cmd --reload  # CentOS 放行
sudo ufw allow 8000/tcp   # Ubuntu 放行
```

阿里云控制台 → 安全组 → 入方向需有：允许 TCP 8000/8000，授权对象 `0.0.0.0/0`。

### 2.5 改管理员密码

```bash
docker exec -i campus python - <<'PY'
from app.database import get_conn
from app.security import hash_password
c = get_conn()
c.execute("UPDATE users SET password_hash=? WHERE username='admin'", (hash_password('新密码'),))
c.commit()
print('已修改')
PY
```

### 2.6 常见问题速查

| 现象 | 排查命令 | 解决办法 |
|---|---|---|
| 容器 Exited | `docker logs campus` | 看启动报错；多半是启动命令/入口问题 |
| 页面打不开 | `ss -tlnp`、防火墙、安全组 | 监听 0.0.0.0 + 放行 8000 |
| 页面能开但问答报错 | `docker exec campus printenv DEEPSEEK_API_KEY` | 为空就用 `-e` 注入真实 Key |
| 高德/天气不可用 | `docker exec campus printenv AMAP_API_KEY` | 确认 `.env` 或 `-e` 里有 Key |
| 浏览器 MCP 离线 | 查看 `docker logs campus` | 属于可选功能，不影响问答；如需安装 Chromium 需进容器装 |
| 想恢复初始数据 | 删除容器内 `data/campus.db` 后重启 | `docker exec campus rm -f /app/data/campus.db && docker restart campus` |
| 学生收不到审批/工单推送 | `docker exec -i campus python -c "import sqlite3;c=sqlite3.connect('/app/data/campus.db');print(c.execute('select count(*) from notifications').fetchone())"` | 有记录说明推送正常，让学生刷新页面（前端每 5 秒轮询一次） |
| 知识库是空的 / 检索没结果 | `docker exec campus ls /app/seed/kb_files` | 文件没进镜像就重新 build；镜像里有就连后台上「重新扫描知识文件」 |
| 后台看不到「检索测试」 | 版本旧 | 确认 `app/static/admin.html` 已更新并重新 build，浏览器按 Ctrl+F5 强刷 |

## 三、一句话速记

- 本地跑：`scripts\start.bat`，看 127.0.0.1:8000
- 服务器跑：`cd /project/bhu_campus_agent && docker build -t campus-agent .` → `docker rm -f campus` → `docker run -d --name campus --restart=always -p 8000:8000 -v /project/bhu_campus_agent/data:/app/data -e PYTHONUNBUFFERED=1 -e DEEPSEEK_API_KEY=sk-xxx -e AMAP_API_KEY=你的key campus-agent`
- 重启自愈：容器 `--restart=always` + Docker `systemctl enable docker`
- 看日志：`docker logs campus`；重启：`docker restart campus`
- 改完前端看效果：浏览器 **Ctrl+F5** 强刷（样式/脚本有缓存）；改完后端：`docker restart campus`
